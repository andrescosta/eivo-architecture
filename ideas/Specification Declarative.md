# Specification: Declarative Text-Based DSL and Runtime for Interactive Educational Multimedia

## 1. Problem Statement

Explaining complex technical, algorithmic, and educational concepts—ranging from distributed consensus protocols (e.g., Paxos, Raft) to 90s-style Flash CD-ROM educational games (e.g., regular verbs for toddlers)—requires dynamic visual aids, state transitions, and interactive mechanics.

Currently, authoring these scenes requires either:
* **Static diagramming/animation DSLs** (e.g., Mermaid.js, Lottie) that lack interactive hitboxes, drag-and-drop mechanics, or custom shape physics.
* **Full game engines** (e.g., Godot, Phaser) that require imperatively writing code or using complex visual GUI editors rather than accepting plain-text definitions generated by humans, LLMs, or declarative editors.

### Goal
Define an open-source, web-compatible architecture where interactive scenes—spanning vector shapes, keyframe animations, drag-and-drop hitboxes, and event handlers—are declared in plain text (JSON/YAML) and rendered inside an MDX document or web application via a browser-based JavaScript runtime.

## 4. Alternative Solutions Considered

| Alternative | Category | Strengths | Limitations / Why Not Selected as Single Solution |
| :--- | :--- | :--- | :--- |
| **Mermaid.js** | Diagram DSL | Human & LLM-friendly text format; native browser SVG rendering. | Cannot handle arbitrary 2D shapes, drag-and-drop hitboxes, or mini-game logic. |
| **Godot Engine (Wasm)** | Game Engine | Complete 2D/3D physics, node trees, and animation tools. | Large bundle footprint (15MB–30MB WebAssembly load), lacks native text-DSL parser out-of-the-box. |
| **Penrose** | Diagram DSL | Excellent separation of Domain, Substance, and Style text DSLs. | Designed for static diagram layout via constraint optimization; lacks game physics and event loops. |
| **Slint UI** | Declarative GUI | `.slint` DSL compiles to WebAssembly; native layout & touch state machine. | Excellent for reactive UI and card games, but lacks built-in 2D rigid-body collision physics. |
| **Rive** | Motion/State Machine | State machines and bone animations execute via Wasm. | Primarily designed for visual editor export rather than hand-authored plain text DSLs. |

6.4 Preloading Architecture in DSL RuntimeTo prevent visual pop-in during rendering, the DSL runtime implements an asynchronous image loading cache before triggering scene rendering:TypeScript// DSL Runtime Preloader Module
export class AssetPreloader {
  private cache: Map<string, HTMLImageElement> = new Map();

  async preloadEntities(entities: Array<{ type: string; image?: { src: string } }>): Promise<void> {
    const imageUrls = entities
      .filter((e) => e.type === 'image' && e.image?.src)
      .map((e) => e.image!.src);

    const loadPromises = imageUrls.map((src) => {
      if (this.cache.has(src)) return Promise.resolve();
      return new Promise<void>((resolve, reject) => {
        const img = new Image();
        img.crossOrigin = 'anonymous';
        img.onload = () => {
          this.cache.set(src, img);
          resolve();
        };
        img.onerror = () => reject(new Error(`Failed to load asset: ${src}`));
        img.src = src;
      });
    });

    await Promise.all(loadPromises);
  }

  getLoadedImage(src: string): HTMLImageElement | undefined {
    return this.cache.get(src);
  }
}

Implementation Strategy & Runtime Engines8.1 Graphical Rendering Engine Selection (Konva.js)For Phase 2 runtime execution, Konva.js (MIT License) is selected as the underlying 2D scene-graph and rendering engine for the <Scene /> component.Architectural Rationale:AST Mapping: Konva's object-oriented Stage -> Layer -> Node structure mirrors the JSON/YAML DSL scene -> entities graph.Declarative Asset Binding: Handles standard .svg, .png, and .jpg image references via Konva.Image node bindings natively.Hit-Testing & Interaction: Offloads manual pointer mathematical calculations by providing native draggable, hover detection, and pointer event dispatches out of the box.Bundle Footprint: ~45 KB gzipped, ensuring fast initial page loads when embedded in MDX blog posts or documentation sites.8.2 Konva.js Runtime Implementation PrototypeTypeScriptimport React, { useEffect, useRef } from 'react';
import Konva from 'konva';
import { AssetPreloader } from './AssetPreloader';

interface SceneProps {
  ast: any; // Parsed DSL AST Object
}

export const Scene: React.FC<SceneProps> = ({ ast }) => {
  const containerRef = useRef<HTMLDivElement>(null);
  const preloaderRef = useRef(new AssetPreloader());

  useEffect(() => {
    if (!containerRef.current) return;

    let stage: Konva.Stage;

    async function initScene() {
      // 1. Preload image assets
      await preloaderRef.current.preloadEntities(ast.entities);

      // 2. Initialize Stage & Main Layer
      stage = new Konva.Stage({
        container: containerRef.current!,
        width: ast.scene.width,
        height: ast.scene.height,
      });

      const layer = new Konva.Layer();
      stage.add(layer);

      // 3. Render Entities
      ast.entities.forEach((entity: any) => {
        if (entity.type === 'circle') {
          const circle = new Konva.Circle({
            id: entity.id,
            x: entity.transform.x,
            y: entity.transform.y,
            radius: entity.geometry?.radius || 20,
            fill: entity.style?.fill || '#000',
            draggable: entity.interaction?.draggable ?? false,
          });
          layer.add(circle);
        } else if (entity.type === 'image' && entity.image?.src) {
          const loadedImg = preloaderRef.current.getLoadedImage(entity.image.src);
          if (loadedImg) {
            const konvaImg = new Konva.Image({
              id: entity.id,
              x: entity.transform.x,
              y: entity.transform.y,
              image: loadedImg,
              width: entity.geometry?.width,
              height: entity.geometry?.height,
              draggable: entity.interaction?.draggable ?? false,
            });
            layer.add(konvaImg);
          }
        }
      });

      layer.draw();
    }

    initScene();

    return () => {
      if (stage) stage.destroy();
    };
  }, [ast]);

  return <div ref={containerRef} style={{ background: ast.scene.background || '#fff' }} />;
};
