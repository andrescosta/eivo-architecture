Activity types
Learning
The core authored content of each lesson — explanations, examples, diagrams, and structured material written once and reused every time the lesson is accessed.
Gym
Practice activities generated by AI at runtime — each learner gets a fresh set every session. Includes fill-in-the-blank exercises, multiple choice questions, flashcard sets, and playrooms for open practice.
Evaluation
Assessment activities that measure learner progress. A Challenge is a focused task; a Championship is a broader evaluation spanning more content.
Space
A free practice environment available at the course level — one per Eivolet.
